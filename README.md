# 🎓 СОЦИУМ: жизнь в обществе

**Обучающая игра по обществознанию для 10 класса (§5)**

---

## 📚 О игре

Интерактивная сюжетная игра, в которой ученики проживают жизнь персонажа в вымышленном городе Социум, изучая понятия:
- Общество как система
- Социальные институты
- Социальная структура и стратификация
- Социальный статус и роли
- Социальная мобильность
- Социальные конфликты

**Продолжительность:** 20-30 минут

---

## 👨‍🏫 Система отслеживания прогресса для учителя

### Как это работает?

#### 1. **Код ученика**
При создании персонажа каждый ученик получает уникальный код (например: `SOC-A3K7M9`), который отображается:
- В верхней части игрового экрана
- На экране "Социологический паспорт"

#### 2. **Экспорт результатов**
Ученик может экспортировать свой прогресс в JSON-файл:
- Кнопка **"📤 Экспорт для учителя"** в нижней панели игры
- Кнопка **"📤 Экспорт для учителя"** на экране паспорта

Файл сохраняется как: `СОЦИУМ_SOC-A3K7M9_ИмяУченика.json`

#### 3. **Режим учителя**
Учитель открывает игру и нажимает кнопку **"👨‍🏫 Режим учителя"** в главном меню.

**Возможности:**
- 📥 **Импорт файлов** учеников (можно загрузить несколько файлов сразу)
- 📊 **Автоматическая оценка** на основе:
  - Пройденных сцен (30%)
  - Результатов мини-игр (25%)
  - Полученных достижений (20%)
  - Финальной концовки (15%)
  - Изучения глоссария (10%)
- ✏️ **Ручная корректировка** оценки и добавление комментария
- 📄 **Экспорт отчёта** в текстовый файл (TXT)
- 📊 **Экспорт в CSV** для работы в Excel

### Что видит учитель?

#### Статистика:
- Общее количество учеников
- Средняя оценка по классу
- Количество завершивших игру
- Распределение оценок (5/4/3/1-2)

#### Таблица учеников:
| Код | Имя | Оценка | Прогресс | Действия |
|-----|-----|--------|----------|----------|
| SOC-A3K7M9 | Иван Петров | 5 | 28 сцен | 🗑️ |
| SOC-B4L8N0 | Мария Сидорова | 4 | 25 сцен | 🗑️ |

#### Детальная информация по ученику:
При клике на ученика учитель видит:
- **Данные персонажа:** имя, возраст, район, семья
- **Прогресс:** количество сцен, достижений, статусов, ролей
- **Ресурсы:** доход, образование, престиж, власть и др.
- **Автоматическая оценка** с возможностью изменения
- **Поле для комментария**

## 🚀 Инструкция для учителя

### Шаг 1: Подготовка
1. Откройте файл игры в браузере
2. Убедитесь, что все ученики также могут открыть игру

### Шаг 2: Объяснение ученикам
Скажите ученикам:
> "Когда вы завершите игру, нажмите кнопку **'📤 Экспорт для учителя'** и отправьте мне полученный JSON-файл. Запомните свой код ученика (начинается с SOC-)."

### Шаг 3: Сбор результатов
1. Ученики отправляют вам файлы (через email, мессенджер, облако и т.д.)
2. Сохраните все файлы в одну папку

### Шаг 4: Импорт в систему
1. Откройте игру и нажмите **"👨‍🏫 Режим учителя"**
2. Нажмите **"Выбрать файлы"**
3. Выберите все JSON-файлы учеников (можно несколько сразу)
4. Система автоматически загрузит и оценит каждого ученика

### Шаг 5: Анализ и выставление оценок
1. Просмотрите статистику класса
2. При необходимости скорректируйте оценки (кликните на ученика)
3. Добавьте комментарии для каждого ученика
4. Нажмите **"💾 Сохранить оценку"**

### Шаг 6: Экспорт отчёта
- **TXT файл** — для просмотра и печати
- **CSV файл** — для работы в Excel/Google Sheets

## 📊 Критерии автоматической оценки

| Баллы | Оценка | Описание |
|-------|--------|----------|
| 90-100% | **5** | Отлично |
| 75-89% | **4** | Хорошо |
| 60-74% | **3** | Удовлетворительно |
| 40-59% | **2** | Неудовлетворительно |
| < 40% | **1** | Требуется повторное прохождение |

**Распределение баллов:**
- Прогресс по сюжету: 30 баллов
- Мини-игры: 25 баллов
- Достижения: 20 баллов
- Финальная концовка: 15 баллов
- Изучение глоссария: 10 баллов

## 💾 Локальное хранение

Все данные учителя хранятся локально в браузере (localStorage):
- Ключ: `socicum_teacher_students`
- Данные не передаются на сервер
- При очистке кэша браузера данные удаляются

**Рекомендация:** после выставления оценок экспортируйте отчёт в TXT или CSV для архивации.

## 📝 Примеры использования

### Сценарий 1: Домашнее задание
1. Учитель объясняет тему §5 на уроке
2. Даёт домашнее задание: пройти игру и экспортировать результаты
3. Ученики отправляют файлы через электронный журнал
4. Учитель импортирует файлы и выставляет оценки

### Сценарий 2: Контрольная работа
1. На уроке ученики открывают игру на компьютерах/планшетах
2. Проходят игру (20-30 минут)
3. Экспортируют результаты на флешку или через облако
4. Учитель сразу проверяет и выставляет оценки

### Сценарий 3: Проектная работа
1. Ученики проходят игру индивидуально
2. Анализируют свой "Социологический паспорт"
3. Готовят презентацию о своём персонаже
4. Учитель оценивает и игру, и презентацию
