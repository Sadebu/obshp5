## 📖 О проекте

**"СОЦИУМ"** — это браузерная образовательная игра, которая помогает ученикам 10 класса изучить параграф 5 "Общество как система. Человек в системе социальных взаимодействий" через интерактивное повествование.

Игрок создаёт персонажа и проживает его жизнь от 14 до 32 лет, принимая решения в ключевых социальных ситуациях. Через сюжет, выборы и мини-игры ученики на практике понимают основные социологические понятия.

### 🎯 Педагогические цели

- ✅ Понять общество как систему взаимосвязанных элементов
- ✅ Различать социальные институты и их функции
- ✅ Осознать разницу между предписанным и достигаемым статусом
- ✅ Понять механизмы социальной мобильности
- ✅ Научиться разрешать социальные конфликты
- ✅ Применять теоретические знания на практике

## 🚀 Быстрый старт

### Для учеников

1. Откройте [ссылку на игру](#-онлайн-версия)
2. Нажмите **"🎮 Новая игра"**

4. Проходите сюжет и делайте выборы
5. В конце нажмите **"📤 Экспорт для учителя"**

4. Просматривайте результаты и выставляйте оценки
5. Экспортируйте отчёты в TXT или CSV

## 🎮 Возможности игры

### Сюжет и механики

- **3 акта** жизни персонажа (14-32 года)
- **30+ сюжетных сцен** с ветвлением
- **8 ресурсов** с визуальными индикаторами
- **Система статусов и ролей** (предписанные и достигаемые)
- **7 разных концовок** в зависимости от выборов
- **5 интерактивных мини-игр**
- **10 достижений** за особые действия
- **Автосохранение** прогресса

### Мини-игры

1. 🕸️ **Паутина общества** — соедини элементы общества
2. 🔺 **Социальная пирамида** — распредели людей по слоям
3. 🏢 **Социальный лифт** — выбери каналы мобильности
4. 🔗 **Конфликтный узел** — отличи причину от повода
5. 🏛️ **Институциональный пазл** — распредели ситуации по институтам

### Режим учителя

- 📥 Импорт результатов учеников (JSON)
- 📊 Автоматическая оценка по 5-балльной системе
- 👥 Таблица учеников со статистикой
- ✏️ Ручная корректировка оценок и комментарии
- 📄 Экспорт отчёта в TXT
- 📊 Экспорт в CSV для Excel/Google Sheets

## 📊 Система оценивания

Автоматическая оценка рассчитывается на основе:

| Критерий | Вес | Описание |
|----------|-----|----------|
| Прогресс по сюжету | 30% | Количество пройденных сцен |
| Мини-игры | 25% | Средний результат мини-игр |
| Достижения | 20% | Количество полученных ачивок |
| Финальная концовка | 15% | Тип полученной концовки |
| Изучение глоссария | 10% | Количество изученных терминов |

**Шкала оценок:**
- 90-100% → **5** (Отлично)
- 75-89% → **4** (Хорошо)
- 60-74% → **3** (Удовлетворительно)
- 40-59% → **2** (Неудовлетворительно)
- < 40% → **1** (Требуется повторение)

## 📦 Установка и запуск

### Требования

- Node.js 18+ 
- npm или yarn

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/ваш-username/socicum-game.git
cd socicum-game

# Установите зависимости
npm install
```

### Разработка

```bash
# Запустите dev-сервер
npm run dev

# Откройте http://localhost:3000
```

### Сборка

```bash
# Соберите production-версию
npm run build

# Предпросмотр production-версии
npm run preview
```

## 🌍 Деплой

### Netlify (рекомендуется)

**Вариант 1: Drag & Drop**
1. Соберите проект: `npm run build`
2. Перетащите папку `dist` на [app.netlify.com/drop](https://app.netlify.com/drop)
3. Готово!

**Вариант 2: Через Git**
1. Запушьте код в GitHub
2. Подключите репозиторий к Netlify
3. Настройте автоматический деплой

📖 [Подробная инструкция по деплою](DEPLOY.md)

### Vercel

```bash
# Установите Vercel CLI
npm i -g vercel

# Задеплойте
vercel
```

### GitHub Pages

1. Соберите проект: `npm run build`
2. Загрузите папку `dist` в branch `gh-pages`
3. Включите GitHub Pages в настройках репозитория

### Собственный сервер

```bash
# Соберите проект
npm run build

# Скопируйте dist на сервер
scp -r dist/* user@server:/var/www/socicum/
```
