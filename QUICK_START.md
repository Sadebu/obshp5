# 🚀 Быстрый деплой за 5 минут

## Самый простой способ: Netlify Drag & Drop

### Шаг 1: Соберите проект
```bash
npm run build
```

### Шаг 2: Откройте Netlify
Перейдите на [app.netlify.com/drop](https://app.netlify.com/drop)

### Шаг 3: Загрузите файлы
Перетащите папку **`dist`** на страницу Netlify

### Шаг 4: Готово!
Netlify даст вам ссылку вида `https://random-name.netlify.app`

Можете изменить имя сайта в настройках на что-то вроде `socicum-game`

---

## Альтернативные способы

### Vercel (через CLI)
```bash
npm i -g vercel
vercel
```

### GitHub Pages
1. Загрузите код в GitHub репозиторий
2. В Settings → Pages выберите branch `main` и папку `/dist`
3. Получите ссылку `https://username.github.io/repo-name`

📖 [Подробные инструкции](DEPLOY.md)

---

## После деплоя

1. Откройте сайт по ссылке
2. Проверьте, что игра работает
3. Отправьте ссылку ученикам
4. Используйте "Режим учителя" для проверки результатов

---

**Всё! Ваша игра теперь доступна онлайн 24/7 🎉**
