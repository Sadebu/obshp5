# 👨‍🏫 Инструкция для учителя

## 🎯 Как использовать игру "СОЦИУМ" в учебном процессе

### Шаг 1: Подготовка (5 минут)

1. **Откройте сайт с игрой** по ссылке, которую вам предоставил администратор
2. **Проверьте доступ** — игра должна открываться в браузере
3. **Подготовьте учеников** — у каждого должен быть доступ к интернету и браузер

### Шаг 2: Объяснение задания (10 минут)

Скажите ученикам:

> "Сегодня мы играем в образовательную игру 'СОЦИУМ'. Это интерактивный симулятор, где вы проживёте жизнь персонажа в вымышленном городе и на практике изучите понятия из параграфа 5: общество как система, социальные институты, статусы, роли, мобильность и конфликты.
>
> **Важно:**
> - Игра длится 20-30 минут
> - Запомните свой код ученика (начинается с SOC-)
> - В конце игры нажмите кнопку '📤 Экспорт для учителя'
> - Отправьте мне полученный JSON-файл через [укажите способ: email/мессенджер/облако]"

### Шаг 3: Игра (20-30 минут)

Ученики:
1. Создают персонажа (выбирают имя, пол, район, семью)
2. Проходят через 3 акта жизни персонажа
3. Делают выборы в сюжетных сценах
4. Проходят мини-игры
5. Получают "Социологический паспорт" в конце
6. Экспортируют результаты в JSON-файл

### Шаг 4: Сбор результатов (после урока)

Ученики отправляют вам JSON-файлы. Каждый файл содержит:
- Код ученика (SOC-XXXXXX)
- Имя персонажа
- Все выборы и решения
- Результаты мини-игр
- Финальную концовку
- Все ресурсы и статусы

### Шаг 5: Импорт и оценка (15-20 минут)

1. **Откройте игру** по той же ссылке
2. **Нажмите "👨‍🏫 Режим учителя"** в главном меню
3. **Нажмите "Выбрать файлы"** и загрузите все JSON-файлы учеников
4. **Система автоматически:**
   - Импортирует данные каждого ученика
   - Рассчитает оценку по 5-балльной системе
   - Покажет статистику класса

5. **Просмотрите результаты:**
   - Кликните на ученика для детального просмотра
   - При необходимости скорректируйте оценку
   - Добавьте комментарий

6. **Экспортируйте отчёт:**
   - Нажмите "📄 Отчёт TXT" для текстового файла
   - Нажмите "📊 Экспорт CSV" для Excel/Google Sheets

## 📊 Критерии автоматической оценки

Оценка рассчитывается на основе 5 критериев:

| Критерий | Вес | Что оценивается |
|----------|-----|-----------------|
| Прогресс по сюжету | 30% | Количество пройденных сцен |
| Мини-игры | 25% | Средний результат всех мини-игр |
| Достижения | 20% | Количество полученных ачивок |
| Финальная концовка | 15% | Тип полученной концовки |
| Изучение глоссария | 10% | Количество изученных терминов |

**Шкала оценок:**
- 90-100% → **5** (Отлично)
- 75-89% → **4** (Хорошо)
- 60-74% → **3** (Удовлетворительно)
- 40-59% → **2** (Неудовлетворительно)
- < 40% → **1** (Требуется повторное прохождение)

## 🎓 Педагогические цели

Игра помогает ученикам:

✅ **Понять общество как систему** — через визуализацию связей между элементами  
✅ **Различать социальные институты** — через взаимодействие с ними в игре  
✅ **Осознать разницу между статусами** — предписанный vs достигаемый  
✅ **Понять механизмы мобильности** — через использование социальных лифтов  
✅ **Научиться разрешать конфликты** — через прохождение этапов конфликта  
✅ **Применять теорию на практике** — через сюжетные ситуации

## 💡 Советы по использованию

### Для урока:
- Выделите 1 учебный час (45 минут)
- 10 минут — объяснение задания
- 25 минут — прохождение игры
- 10 минут — обсуждение результатов

### Для домашней работы:
- Дайте ссылку на игру
- Попросите пройти игру дома
- Соберите JSON-файлы через электронный журнал
- Проверьте результаты на следующем уроке

### Для проектной работы:
- Ученики проходят игру индивидуально
- Анализируют свой "Социологический паспорт"
- Готовят презентацию о своём персонаже
- Сравнивают результаты с одноклассниками

## 📈 Анализ результатов

### Что показывает статистика:

**Средняя оценка класса:**
- 4.5-5.0 — отличный результат, материал усвоен
- 3.5-4.4 — хороший результат, есть пробелы
- 2.5-3.4 — удовлетворительно, нужно повторение
- < 2.5 — требуется дополнительная работа

**Распределение оценок:**
- Много пятёрок — материал понятен
- Много троек — нужно объяснить сложные темы
- Много двоек — требуется повторное изучение

**Популярные концовки:**
- "Восходящая мобильность" — ученики понимают социальные лифты
- "Социальный мост" — ученики умеют разрешать конфликты
- "Одиночка" — ученики не использовали социальные связи
- "Нисходящая мобильность" — ученики делали неудачные выборы

## 🔧 Технические вопросы

### Что делать, если:

**Ученик не может открыть игру:**
- Проверьте доступ к интернету
- Попробуйте другой браузер
- Очистите кэш (Ctrl+Shift+Del)

**Ученик потерял JSON-файл:**
- Игра автоматически сохраняется в браузере
- Ученик может нажать "💾 Сохранить" и экспортировать снова

**Не удаётся импортировать файл:**
- Проверьте, что файл имеет расширение .json
- Убедитесь, что файл не повреждён
- Попробуйте загрузить файл заново

**Оценка кажется несправедливой:**
- Вы можете вручную изменить оценку
- Добавьте комментарий для ученика
- Объясните критерии оценки на уроке
